\# SOLAR INDUSTRY CHATBOT

\# INSTALLATION GUIDE



\---



\## 1. Requirements



Before running the Solar Industry Chatbot, make sure the following software is installed:



\- Windows 10/11

\- Python 3.12 or newer

\- Ollama

\- Git (optional)

\- Web browser



The project is designed to run locally.
