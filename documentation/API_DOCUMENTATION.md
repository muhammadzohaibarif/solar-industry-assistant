\# SOLAR INDUSTRY CHATBOT

\# API DOCUMENTATION



\---



\## 1. Overview



The Solar Industry Chatbot provides a Flask REST API that allows the web frontend or other applications to communicate with the chatbot backend.



The API handles:



\- Health checking

\- Chat requests

\- Conversation creation

\- Conversation memory

\- Solar calculations

\- Battery calculations

\- Inverter calculations

\- Solar system recommendations

\- Knowledge-based questions
