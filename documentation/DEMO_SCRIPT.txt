SOLAR INDUSTRY ASSISTANT
FINAL DEMONSTRATION SCRIPT
==========================

1. INTRODUCTION

This project is the Solar Industry Assistant, an AI-powered solar energy chatbot.

It combines a locally hosted Llama 3.2 model through Ollama, Retrieval-Augmented Generation, solar calculation tools, conversation memory, a Flask backend, SQLite, and a web frontend.

2. FRONTEND

Open the Solar Assistant web interface.

Explain:

"This is the user-facing interface where users can ask natural-language questions about solar energy."

3. SOLAR CALCULATION

Ask:

"My home uses 300 kWh per month. How many 550W solar panels do I need?"

Expected result:

- Estimated Solar Capacity: 2.5 kW
- Estimated Number of Panels: 5
- Actual Panel Capacity: 2.75 kW

Explain:

"The chatbot detects the solar-sizing request and sends it to the calculation tool instead of relying only on the language model."

4. SYSTEM RECOMMENDATION

Ask:

"I have a reliable grid connection and I don't need battery backup. Which solar system type should I choose?"

Expected result:

ON-GRID

Explain:

"The recommendation engine evaluates grid availability, reliability, backup requirements, and battery requirements."

5. RAG + LLM

Ask:

"What is the difference between lithium-ion and lead-acid batteries for solar systems?"

Explain:

"This demonstrates the knowledge-base and RAG pipeline combined with the local Llama 3.2 model."

6. CONVERSATION MEMORY

Ask:

"Based on my earlier question, how many 550W panels did you say I needed?"

Expected result:

Approximately 5 panels.

Explain:

"The assistant remembers information from the current conversation using SQLite-backed conversation memory."

7. BACKEND

Show the Flask backend terminal.

Explain:

"The frontend communicates with a Flask REST API, which connects the user interface, chatbot engine, calculation tools, RAG system, Ollama, and database."

8. KNOWLEDGE BASE

Show the Knowledge_base folder.

Explain:

"The knowledge base contains structured information about panels, batteries, inverters, installation, maintenance, sizing, systems, pricing, warranties, energy consumption, and FAQs."

9. FINAL STATEMENT

"The project demonstrates how a local large language model can be combined with deterministic calculation tools, RAG, memory, and a web application to create a practical domain-specific AI assistant."
